# 家計簿

スマホでも使える、シンプルな家計簿Webアプリです。`index.html` 1ファイルだけで動きます。

## できること

- 支出の入力（金額・カテゴリ・日付・メモ）
- 月ごとの合計と前月比
- カテゴリ別の集計（割合つき）
- 直近12か月の支出グラフ（棒をタップするとその月へ移動）
- 明細の一覧と削除
- CSVでの保存・読み込み（バックアップや端末の移行用）

## 使い方

`index.html` をブラウザで開くだけです。スマホで使うときは、GitHub Pages などで公開して「ホーム画面に追加」するとアプリのように使えます。

## データについて

入力したデータは、開いているブラウザの中（localStorage）に保存されます。サーバーには送信されません。
別の端末やブラウザとは共有されないため、移行やバックアップはCSVで行ってください。
